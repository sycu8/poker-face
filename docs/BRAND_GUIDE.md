# Poker Faces brand guide

Poker Faces is not a casino. It is a private digital table where friends play, talk and stay connected.

**Primary tagline:** Your table. Your people.
**Supporting line:** Private poker nights, wherever everyone is.

## Color tokens

| Token | Hex | Use |
| --- | --- | --- |
| Night | `#07100D` | Main background |
| Ink Green | `#0B2118` | Raised dark surfaces |
| Felt | `#0F4C35` | Poker table / primary brand field |
| Felt Bright | `#176B49` | Hover, active, positive accents |
| Gold | `#F4BC56` | Primary CTA, focus, important chip values |
| Gold Deep | `#B87822` | Light-background gold text |
| Ivory | `#F6F2E7` | Cards and primary text |
| Mist | `#A7B8AF` | Secondary text |
| Danger | `#F06A6A` | Destructive / connection failure |
| Info | `#72B7FF` | Neutral system notice |

Never use red as the main brand color.

## Typography

- UI / wordmark: Manrope 400, 600, 700, 800 (self-hosted via `@fontsource/manrope`)
- Display headlines: Fraunces 600/700 (`@fontsource/fraunces`)
- Numeric table data: Manrope tabular nums
- Card ranks: high-legibility system serif

## Logo files

- `logo/poker-faces-mark.svg` — app icon / avatar
- `logo/poker-faces-wordmark-dark.svg` — dark surfaces
- `logo/poker-faces-wordmark-light.svg` — light surfaces
- `logo/poker-faces-monochrome.svg` — one-color fallback

Clear space: ≥ 1/4 mark width. Mark min 24px. Wordmark min 180px wide.

## Voice

Use: private room, friends, table, take a seat, join request, virtual chips, voice on/off, next hand.
Avoid: win big, real stakes, casino, gambling, jackpot, deposit/withdraw/wallet/payout, guaranteed win.
When “cash game” could be misunderstood, say “continuous table” or “ongoing room”.
